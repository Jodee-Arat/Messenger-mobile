45)3. Нет forward secrecy для групповых чатов
Один статический groupKey (Kuznechik) используется всеми участниками для всех сообщений. Компрометация ключа раскрывает все прошлые и будущие сообщения группы. Ротация ключей происходит только при leave/remove участника (useSecretChat.ts — subKeyRotation), но не периодически. (можно потом сделать ротацию ключей, например, раз в неделю или при достижении определённого количества сообщений по идеи должно быть не так сложно, но это уже будет потом)
46)Нет Double Ratchet / нет forward secrecy для DM
После X3DH один и тот же sessionKey используется для всех последующих сообщений через buildSessionMsgEnvelope. Нет ratchet-механизма. Компрометация sessionKey раскрывает все DM-сообщения после X3DH. (можно потом сделать Double Ratchet, но это уже будет потом)
47)узнать как это можно исправить 7. OPK index resolution может привести к десинхронизации — useSecretChat.actions.ts:510-575
resolveMyUsedOpkPrivateKey ищет OPK по публичному значению через findIndex. Если сервер обновил бандл, а клиент ещё нет — opkIndex будет -1, и OPK пропускается. X3DH без OPK всё ещё работает, но слабее (3 DH вместо 4).
